# Tailscale

它是私人VPN服務，可以建立私人的VPN

將個人的不同工作站，形成一個免費的區域網路

這是目前全球創客和工程師最愛的方案。它會利用 VPN 技術，在你的 Windows 筆電與家裡的香橙派之間，拉出一條專屬的隱形安全網路線。

它是怎麼運作的： 你只要在「家裡香橙派」和「Windows 筆電」上都安裝 Tailscale 軟體，並登入同一個帳號（例如你的 Google 帳號）。Tailscale 就會分發一個全宇宙唯一的虛擬固定 IP 給你的香橙派（例如 100.12.34.56）。

你的開發體驗有何改變：
無論你的筆電是在家裡、在公司、還是在路易莎咖啡廳，你只需要把 .bat 檔和網路磁碟機裡的 192.168.0.135 全部改成這組 100.12.34.56。點擊 .bat 一樣秒跑，完全不需要改任何開發習慣！

為什麼推薦它：

極度安全： 網路是完全加密的，外人絕對連不進來。

免動路由器： 你不需要去動家裡中華電信或聯寬的 Wi-Fi 分享器設定，安裝完直接就能用。
